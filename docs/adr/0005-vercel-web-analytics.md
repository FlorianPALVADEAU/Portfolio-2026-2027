# 0005. Vercel Web Analytics

- Status: accepted
- Date: 2026-10-16

## Context

Analytics must be free and light, and respect visitors' privacy. The site is hosted on Vercel.

## Decision

Use Vercel Web Analytics and Speed Insights rather than Google Analytics.

## Consequences

No cookie banner and a small script, with real-user performance data next to Lighthouse results. Reporting is less detailed than a full analytics suite and tied to the hosting provider.
